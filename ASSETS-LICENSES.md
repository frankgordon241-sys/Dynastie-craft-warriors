# Ressources 3D — Dynastie Craft Warriors

Les ressources suivantes sont chargées à la demande dans le prototype Three.js depuis Gobkit. Elles ne sont pas copiées dans ce dépôt : le jeu les télécharge depuis les URL publiques lors du lancement. Une connexion Internet est donc nécessaire.

## Gobkit — CC0 1.0 Universal

Source : https://gobkit.com/freebies  
Licence : https://creativecommons.org/publicdomain/zero/1.0/

Fichiers utilisés :
- `human013/Prince.glb` — personnage provisoire du héros.
- `human013/CrownedPrincess.glb` — personnage provisoire de la princesse.
- `human006/OrcWarbandChampion.glb` — adversaire orc provisoire (ce n'est pas encore le roi gobelin définitif).
- `environment/TreeHigh001.glb`
- `environment/TreeHigh002.glb`
- `environment/TreeMed001.glb`
- `environment/TreeMed002.glb`

La page de la bibliothèque indique que les modèles gratuits sont en glTF 2.0/GLB sous CC0 1.0, utilisables et modifiables y compris dans un jeu commercial, sans attribution obligatoire.

## Limites connues

- Ces personnages sont des modèles fantasy stylisés/low-poly, pas encore les personnages manga 3D réalistes définitifs de l'histoire.
- Le champion orc est seulement un adversaire de test, pas le roi gobelin décrit dans le scénario.
- Les fichiers sont chargés depuis Gobkit au démarrage : ils ne sont pas encore embarqués dans le dépôt. Si le service distant est indisponible ou si le téléphone n'a pas Internet, les personnages provisoires déjà présents restent visibles.
- Les modèles et leurs animations doivent encore être testés sur un véritable téléphone Android pour contrôler l'échelle, l'orientation, les performances et les animations.
